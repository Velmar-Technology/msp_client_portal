## 2025-07-03 - [Accessibility & Icon Consistency]
**Learning:** Icon-only buttons (like 'X' for closing or removing items) must have descriptive ARIA labels to be accessible to screen readers. Using proper icons from a library like Lucide is preferred over raw text characters (like '×') for visual and semantic consistency.
**Action:** Always check for missing ARIA labels on icon buttons and ensure consistent icon usage across the application.
